Halo: Bolt Action - Optional Rules v1.7

Introduction
This supplement contains optional rules modules for Halo: Bolt Action, designed primarily for narrative play but usable in any game if both players agree.
These rules are intended to add flavor, cinematic moments, and extra tactical options to Halo: Bolt Action. Unless a module says otherwise, all normal rules still apply.
This is a modular toolbox: players may use all, some, or none of these rules. Each optional rule or section is self-contained wherever possible.
Current modules in this supplement include:
* Heroes (Officer replacement characters with Luck / Resolve / Edge resources)
* Attached Caste Leaders (embedded Spartan / Elite / Brute leaders within eligible squads)
* Template-Free HE (streamlined HE resolution without blast templates)
* Towing & Airlifting (standard artillery towing and VTOL lift operations for certain aircraft)
* And others.

Using Optional Rules
Before the game, players should clearly agree which optional modules are in use. If a rule from this supplement conflicts with a core rule, the optional rule takes precedence.








Simplified List Building
Use this optional rule if both players want a simpler force-building method than full Bolt Action Third Edition platoon construction. If both players use this rule, ignore normal Bolt Action Third Edition platoon requirements except where specifically noted below.
Core Requirements
A force built using this method must include:
 ● At least 1 Platoon Commander.
● At least 2 Infantry units for each Platoon Commander unit taken. Up to 1 transport and tow per unit.
● Any number of Infantry and Artillery units.
If a unit has a restriction per platoon of any type, change platoon to Platoon commander. Company commanders are limited to 1 per army, while other HQ units are 1 per platoon.
Vehicles
If a force includes any Combat Vehicles:
● It must include at least 1 Command Vehicle.
● You must also include at least 1 other Vehicle.
● For every Command Vehicle and 1 other Vehicle you take, you may take 0–3 additional Vehicles. 
● If none of the vehicles in the platoon have the Command Vehicle special rule, and none may purchase it from their profile options, one non-Aircraft vehicle may be given the Command Vehicle special rule for +10 pts, even if its profile entry does not normally allow it.

HERO RESOURCES
Each Hero’s profile lists their starting pools. Heroes may have different amounts of each resource, and each Hero has a unique ability powered by Edge. Unless a rule says otherwise, spent points are deducted from the Hero’s pool for the rest of the game.


Luck (L) — fortune & survivability
   * Re‑roll (1 L): Re‑roll any single die (yours or your opponent’s). The second result stands. This is the only time a re‑roll may itself be re‑rolled (each attempt costs 1 Luck). The Hero does not have to be the unit making the roll in order to use this ability.
   * Brush with Death (1 L): If the Hero would be removed as a casualty, spend 1 Luck to keep it in play.
Resolve (R) — precision, tempo & last‑ditch grit
   * Modify (1 R): After any one D6 made by or against the hero is rolled (before outcomes), adjust that die by +1 or −1. You may spend multiple Resolve on the same die (final value cannot exceed 6 or go below 1).
   * Hand Back an Order (1 R): During the Orders Phase, before the next die is drawn, return the Order Die currently assigned to the Hero or a friendly unit within 6" of it to the bag. That unit counts as not activated this turn. You cannot rewind already‑resolved actions.
Note: Officers still follow normal Snap to Action! limits even if later reactivated with Resolve.
   * Stalemate (1 R): When the Hero’s unit would lose in Close Quarters, you may spend 1 Resolve to force a draw instead. Do this after hits/damage are resolved but before removing the losing unit. 
   * Refuse to Die: If the Hero would be removed as a casualty, roll D6 + remaining Resolve. On 7+, the Hero remains in play and loses 1 Resolve instead.
Edge (E) — spark for hero plays
      * Active (1 E): Spend 1 Edge to use that Hero’s unique ability. 
Using multiple resources (order & stacking)
      * If a Hero has more than one resource available, the controlling player chooses the order to use them. If both affect the same die, resolve Luck (re‑roll) first, then apply Resolve (±1) to the new result.

ATTACHED CASTE LEADER 
This optional rule allows certain units to include an Attached Caste Leader, representing a Spartan, Elite, or Brute fighting as part of another squad.
An Attached Caste Leader is a single model added to an eligible unit during army creation. While at least one non-leader model remains, the leader is part of that unit.
CORE RULE: ONE UNIT
While attached, the leader and the rest of the unit are treated as one unit for all rules purposes except where stated below.
They have:
      * One Order Die
      * One pool of Pin markers
      * Normal unit coherency
      * One activation
      * The same movement order
      * The same objective status
The Attached Caste Leader does not count as a separate unit for order die, objectives, army destruction, or other rules that count units.
When the unit takes an Order test or Morale test, use the highest Veterancy present in the unit.
While an Attached Caste Leader is present, the unit ignores the −1 Morale penalty for losing its NCO and loses the Shirkers special rule if it has it.
SPECIAL RULES WHILE ATTACHED
The Attached Caste Leader and the rest of the unit do not grant their special rules to each other, unless specifically stated otherwise.
For rules that affect the unit as a whole, use the special rules of the unit the leader is attached to. This includes rules affecting:
      * Order tests and Morale tests
      * Routing
      * Movement
      * Compulsory actions
      * Unit-wide behaviour or outcomes
For example, an Attached Leader with Fast, Slow, Flight, Fieldcraft, Behind Enemy Lines, Stubborn or Fanatics does not grant those rules to the unit.
Rules that specifically affect the leader model itself still apply normally. This includes rules affecting:
      * attacks made by the leader
      * attacks directed against the leader
      * the leader’s Damage Value
      * the leader’s saves
      * the leader’s weapons
      * other effects specifically resolved against or from the leader
For example, Strong, Berserker or Strikes First may apply when resolving the leader’s own attacks without granting those rules to the rest of the unit.
Once the leader becomes a separate unit, all of its own special rules apply normally.
SHOOTING
When the unit shoots, the Attached Caste Leader and the rest of the unit must shoot at the same enemy unit, unless another rule specifically allows otherwise.
Targeting an Attached Leader
When shooting at a unit containing an Attached Caste Leader, the attacking player may allocate shots between:
      * the Attached Caste Leader
      * the rest of the unit
Declare how the shots are allocated before rolling To Hit.
A shot may only be allocated to the Attached Caste Leader if the firing model has Line of Sight and range to the leader model.
Resolve shots allocated to the leader separately, using the leader’s own Damage Value, saves and applicable special rules.
Resolve shots allocated to the rest of the unit normally.
Casualties do not spill over between the two groups. If attacks allocated to the rest of the unit cause more casualties than there are non-leader models remaining, the excess casualties are lost. Likewise, attacks allocated to the leader cannot cause casualties among the rest of the unit.
The unit remains a single unit for Pinning, regardless of whether the leader or the rest of the squad was hit.
HE
When using normal HE templates, determine whether the Attached Caste Leader is hit by the position of the template as normal. Any hit affecting the leader is resolved separately against the leader’s own Damage Value and special rules.
If using the Template-Free HE optional rules, after determining the number of HE hits the attacker may allocate one of those hits to the Attached Caste Leader. Resolve that hit separately against the leader.
CLOSE QUARTERS
When fighting a unit containing an Attached Caste Leader, attacks may be directed against either the leader or the rest of the unit.
Before rolling attacks, declare how many attacks are directed against:
      * the Attached Caste Leader
      * the rest of the unit
Resolve attacks directed against the leader using the leader’s own Damage Value and applicable special rules.
Resolve attacks directed against the rest of the unit normally.
Casualties do not spill over between the leader and the rest of the unit.
If all non-leader models are removed during Close Quarters and the Attached Caste Leader survives, the leader immediately becomes a separate unit but remains in the Close Quarters combat.
From that point onward, use the leader’s own profile and special rules in full.
If the combined unit loses Close Quarters and would normally be destroyed, remove the non-leader models as normal. If the leader survives, resolve the result against the leader using its own special rules. For example, a leader with Fanatics may continue fighting even if the unit it was attached to did not have Fanatics.
LEADER BREAKS OFF
If all non-leader models are removed for any reason and the Attached Caste Leader survives, it immediately becomes a separate single-model unit.
From that point onward, it uses its own profile and special rules in full.
The leader retains:
      * all Pin markers currently on the unit
      * the unit’s existing Order Die
      * whether or not the unit has already activated that turn
Do not add another Order Die. The same Order Die continues to represent the leader for the rest of the game.
If the combined unit has already activated that turn, the leader cannot activate again after breaking off.
If the unit has not yet activated and its Order Die is still in the bag, that die may later be assigned to the leader normally.
Breaking Off Because of Routing
If the attached unit fails a Morale test and would rout, first resolve the result against the non-leader models using the unit’s own rules.
If those models are removed but the Attached Caste Leader remains, re-evaluate the same Morale roll using the leader’s own Morale value and special rules.
If the leader would pass the test, or has a rule that prevents it from routing, it remains on the battlefield as a separate unit.
Otherwise, the leader routs as well.
NCO INTERACTION
While the Attached Caste Leader is alive, the unit ignores the −1 Morale penalty for having its NCO removed.
Take the Hit
The first time the Attached Caste Leader would be removed as a casualty, you may instead remove the unit’s NCO.
If you do, the Attached Caste Leader remains in play.
If the unit has no NCO remaining, the leader is removed normally.
ELIGIBILITY
A unit may purchase a maximum of one Attached Caste Leader if it is one of the following:
Regular Infantry Squad, Engineer Squad, Marine Squad, ODST Squad, Grunt Squad, Jackal Squad

Optional rule: Template-Free HE
Use this optional rule if you do not own blast templates, or if you want to speed up gameplay.
When using this rule, ignore HE templates.
HE Hits
If an HE shot hits an Infantry or Artillery unit, do not place a template. Instead, the hit causes a fixed number of hits based on HE size:
      * HE (1") = 3 hits

      * HE (2") = 5 hits

      * HE (3") = 8 hits

      * HE (4") = 12 hits

Maximum Hits
The total number of HE hits caused on a target unit cannot exceed the number of models in that unit (each model can only be hit once).
Down Reaction
If the target unit reacts by going Down, halve the total number of HE hits caused, rounding up.
Multiple HE Hits
If a weapon or unit scores multiple HE hits in the same attack:
         * Add the hits from all successful HE hits together.

         * Apply the maximum hits limit above.

         * If the target is Down, halve the total (rounding up).
All Other HE Rules
Except for the changes above, all other HE rules are resolved as normal, as explained in the Bolt Action Third Edition Rulebook.
































OPTIONAL EQUIPMENT RULES 
These optional rules may be used if both players want equipment such as Active Camouflage and Dual Wielding to have a greater effect on the battlefield.
Active Camouflage
For players who want Stealth to behave more like Halo's Active Camouflage, replace the Stealth special rule with Active Camouflage.
Whenever an enemy unit attempts to target a unit with Active Camouflage, determine Line of Sight normally. If the target would normally be visible, the acting unit must make a Spotting roll using the normal Reduced Visibility rules from the BA rulebook  before it can shoot, assault, or target the camouflaged unit.
If the Spotting roll succeeds, continue the action normally. If it fails, the action against that unit ends as described in the Reduced Visibility rules.
A successful Spotting roll only reveals the Active Camouflage unit to that acting unit for that action. Other enemy units must make their own Spotting rolls normally.
This only affects visibility towards the unit with Active Camouflage. The camouflaged unit itself sees normally.
Firing Reveals the Unit
If a unit with Active Camouflage fires any weapon, its Active Camouflage is disrupted for the remainder of the current Game Turn.
While its Active Camouflage is disrupted:
            * If the battlefield has normal visibility, enemy units no longer need to make Spotting rolls caused by Active Camouflage to target it.
            * If the battlefield is already using Reduced Visibility, the unit follows the normal Reduced Visibility rules, but gains no additional benefit from Active Camouflage.
At the beginning of the next Game Turn, Active Camouflage becomes active again automatically.
Active Camouflage During Reduced Visibility
If the battlefield is already using Reduced Visibility, do not make an additional Spotting roll for Active Camouflage.
Instead, while its Active Camouflage is active, apply an additional -6" Visibility modifier to Spotting rolls made against that unit.
This modifier is cumulative with all normal Reduced Visibility modifiers.
If the unit fires, it loses this additional -6" modifier for the remainder of the current Game Turn, although the normal Reduced Visibility rules continue to apply.
Dual Wielding
Models that are allowed to Dual Wield may purchase Dual Wielding for +2pts per model.
When a model fires Dual Wielded weapons, it may re-roll one failed To Hit roll.
Dual Wielding does not increase the weapon's number of shots, and a die may never be re-rolled more than once.
TOWING & AIRLIFTING
Use this optional rule if you want artillery towing and/or VTOL lift operations in Halo: Bolt Action.
This rule covers:
● Standard artillery towing (as in Bolt Action Third Edition)
● VTOL Airlift / Sling-Load for certain aircraft (such as Pelicans, Spirits, and Phantoms)
Design Notes
 ● Standard towing follows Bolt Action Third Edition towing rules.
● Aircraft do not “tow” in the normal Bolt Action sense. Instead, some aircraft use Airlift.
● Some aircraft may carry troops internally (using the normal Aircraft Transport Rules) and may also carry one airlifted load.
● An airlifted load may be:
○ 1 Artillery unit, or
○ 1 Vehicle up to Medium classification
● Aircraft may never airlift other Aircraft.
Standard Vehicle Towing
Use the normal towing rules from the Bolt Action Third Edition rulebook for artillery. With this exception:
What can be towed
To simplify, a non-aircraft vehicle may only tow an artillery unit if:
● its profile is found within the transports and tows category (See army rulebooks).
Any artillery unit may be towed by that type of vehicle.






VTOL Airlift / Sling-Load
This is the Halo-flavoured add-on for aircraft, allowing them to move artillery or vehicles using lift capability rather than ground towing.
Airlift Capability
Only Pelicans, Phantoms and Spirits may use this rule.
An aircraft with Airlift may carry:
● 1 Artillery unit (Any artillery unit), or
● 1 Vehicle up to Medium classification
Aircraft may not airlift:
● Heavy or Super-heavy vehicles
● other Aircraft
Airlifted Loads Are Separate Units
The aircraft and the airlifted unit remain separate units for activation and orders, as with normal transports.
● They use separate Order Dice
● They activate separately
● The airlifted unit cannot act while airlifted except to deploy/disembark as described below
Picking Up an Airlifted Load
To airlift an artillery unit or vehicle:
            1. The aircraft must be landed.

            2. The unit to be airlifted must be given an order and move toward the aircraft.

            3. If it ends its move within 1" of the aircraft, it may be picked up.

            4. Remove the unit from the board; it is now considered airlifted aboard the aircraft.

Reserve Entry with a Load
An aircraft may enter the battlefield from Reserve already carrying an airlifted unit.
Targeting and Pins While Airlifted
While airlifted:
● The load cannot be targeted separately
● Target the aircraft instead
Pins
If the aircraft suffers pin markers:
● Airlifted artillery / crewed guns suffer the same number of pin markers
● Airlifted vehicles do not receive shared pin markers
Dropping / Deploying an Airlifted Load
To deploy an airlifted unit, the aircraft must be landed.
● The airlifted unit must then be given its own movement order to deploy.
Orders required to deploy
 ● Vehicle: may deploy with an Advance or Run order
● Artillery: must deploy with a Run order 
Restrictions
A unit deployed from Airlift may not make an Assault.
Aircraft Lost While Carrying an Airlifted Load
If an aircraft carrying an airlifted unit becomes:
● Destroyed, or
● Abandoned / Routed
The airlifted entity is immediately dropped and resolved as follows:
Immediate Drop
Place the airlifted unit:
● within 1" of the aircraft base
● more than 1" from any other unit, if possible
The dropped unit then takes a Down order.
Additional Effects If the Aircraft Was Flying When Destroyed
If the airlifted entity is a Vehicle
If the aircraft was flying when destroyed, the airlifted vehicle must immediately roll on the Superficial Damage Table.
If the airlifted entity is Artillery
If the aircraft is destroyed or abandoned/routed while carrying an artillery entity, resolve it using the same rules used for infantry/passengers in your Aircraft Transport Rules (including any crash or forced disembark effects that apply).
Bolt Action Third Edition Compatibility
Except where replaced or expanded by this optional rule, all other towing, transport, and artillery rules are resolved normally using the Bolt Action Third Edition rulebook.






























BEN’S HOUSE RULES
Use this optional section if both players wish to include rules like the cinematic house rules featured in Ben’s games night Halo battle report.
MASTER CHIEF
Use this optional rule if both players agree to field a more heroic, cinematic version of Master Chief.
Design Benchmark
For balance purposes, Master Chief in this format should be treated as roughly equivalent to a 5-man Veteran Spartan squad, plus the value of his additional special rules and equipment, with Resilient.
Spartan-II Resolve
Master Chief never receives Pin markers.
Spartan Regeneration
At the start of each turn, Master Chief regains 1 lost wound.
If Master Chief is issued a Rally order, he regains D3 lost wounds.
Spartan Combat Output
Master Chief fights at full effectiveness even after suffering wounds.
He does not lose attacks, movement, special rules, or command abilities as he loses wounds.
Spartan Reflexes
Each time Master Chief is activated, he may perform two actions during that activation.
Bubble Shield
Once per game, when Master Chief is targeted by an enemy shooting attack, he may immediately deploy a Bubble Shield as a reaction. This does not require an activation.
While the Bubble Shield is active, ignore any shooting attacks against Master Chief.
The Bubble Shield remains in play until the end of the turn, or until Master Chief moves for any reason, whichever comes first.
OVERCHARGE FIRE
When an Anti-Tank Team makes a shooting attack, it may choose to fire at double its normal number of shots.
If it does so, that team cannot fire in its next activation.
VEHICLE HIJACKING
When an Infantry unit assaults an enemy vehicle and scores a successful penetrating hit, it may choose to hijack the vehicle instead of destroying it.
If it does so:
               * remove the infantry unit from the board
               * the vehicle is not destroyed
               * the vehicle comes under that player’s control
               * from that point onward, the hijacked vehicle uses its own Order Die as normal
Hijacked Vehicle Destroyed
If a hijacked vehicle is later destroyed, the unit that hijacked it suffers D3 wounds.
If it survives, place it back on the table as an infantry unit in base contact with the vehicle, or as close as possible.
Abandon Hijacked Vehicle
If Master Chief, or any unit controlling a hijacked vehicle, is given an Advance or Run order, it may choose to abandon the vehicle.
If it does so, the vehicle is immediately destroyed and the controlling unit is placed back on the table as infantry.
GRUNT GRENADE ASSAULT
Use this rule to represent desperate Grunts charging the enemy with live plasma grenades.
After an Assault has been declared and the assault distance has been measured, but before the target reacts, the controlling player may declare that some or all models in the Grunt unit will make Grenade Attacks.
Declare how many Grunts will make Grenade Attacks, then immediately roll one D6 for each declared model:
               * On a 1, a Grunt immediately detonates its grenade prematurely. Remove the model as a casualty and inflict D6 automatic hits on its own unit. Resolve these hits immediately.
               * On a 2+, that Grunt successfully arms its grenades and will make a Grenade Attack if it survives to reach Close Quarters.
Resolve these hits normally using the close quarters rules. After resolving its Grenade Attack, remove that Grunt as a casualty.
A Grunt that makes a Grenade Attack does not make normal Close Quarters attacks too.
A unit that suffers one or more hits from Grunt Grenade Attacks receives 1 Pin marker.
Optional Plasma Grenade Version
If players want the attack to feel more dangerous, Grunt Grenade Attacks are resolved with Pen +1.
MELEE WEAPONS
Use this optional rule if players want melee weapons to feel more decisive without increasing the number of dice rolled.
When using this rule, melee weapons no longer grant +1 extra attack in Close Quarters.
Instead, a model armed with a melee weapon receives +1 to its damage rolls in Close Quarters.
This bonus applies only to attacks made by that model.
Examples
A model with a Melee Weapon does not roll an extra attack. Instead, its Close Quarters attacks gain +1 to damage rolls.
